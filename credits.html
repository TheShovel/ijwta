Open Khuwari

Credits

Khuwari stands on the shoulders of some excellent open source work. Thank you to everyone who made it possible.

Machine learning

RIFE

The RIFE model generates the inbetween frames. It provides the natural motion that makes Khuwari feel alive, and runs entirely in your browser.

Machine learning runtime

ONNX Runtime Web

Runs the RIFE model in the browser with WebAssembly, so no server and no GPU are needed.

Encoding

gifenc

A fast, dependency free GIF encoder used for animated GIF exports.

Encoding

mp4-muxer

Muxes the WebCodecs encoded video stream into MP4 files for video export.

Everything else

Built for Khuwari

The pure JavaScript mesh warp interpolation fallback, the color fill system, the onion skinning, the timeline, the motion blur, and all the rest were written for Khuwari itself.

Art

The mascot

The Khuwari mascot was drawn by hand for the project. It guards the start screen and keeps you company while the machine works.
